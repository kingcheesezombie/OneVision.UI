# OneVision.UI 0.1.49 — Source Configuration Visual Containment

**Scope:** `OVP-SOURCE-CONFIGURATION` presentation refinement; no changes to source execution, mapping logic, identifier algorithms or the OVP-000 foundation.

- Unified theme-derived section tokens across Source Configuration, Profile Results, Field Mapping and the emphasised Identifier Configuration section.
- Retained the approved primary-blue identifier headline and compact two-section Profile composition.
- Added container-width responsiveness for constrained overlays, split editors and full-page layouts. Controls stack, headers wrap, and Run & Profile stays associated with the configuration it executes.
- Added a 520px constrained-workspace gallery toggle and targeted browser regression coverage for desktop viewport / narrow container combinations.
- Preserved app-owned fragments, existing disabled/read-only/stale/saving behaviours, and the existing Web Table discovery/selection interaction.

## Source comparison

Source baseline: `main` at OneVision.UI 0.1.48. The review-approved EAM treatment is used as a **visual reference**, not as an application-specific dependency. Shared section treatment is now token-governed; the application remains responsible for source-specific fields, profiling and mapping decisions. Arbitrary nested application panels keep their structural boundaries rather than having their styles stripped.
