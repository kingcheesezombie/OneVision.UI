# OneVision.UI 0.1.53 — Mapping Rule tree-label pairing regression

**Pattern:** `OVP-MAPPING-RULE` / `OVC-MAPPING-RULE`  
**Foundation:** `OVP-000` unchanged

## Fix

When a condition is active through **Edit pair**, clicking a source or right-hand field label in the governed `OVStructuredFieldTree` now updates that condition. Previously, a label click could only set tree focus, leaving the active condition unchanged. The change is confined to the Mapping Rule composition; the shared field tree behaviour is unchanged.

Both modes remain application-neutral:

- **Direct:** Source field tree and Target field tree.
- **Associated:** Source field tree and Associated field catalogue.

The existing immutable condition/group data model, operator and type validation, callbacks, governing-contract selection and application-supplied execution remain unchanged.

## Verification

Browser regression tests exercise the real demo using **Edit pair** and field label clicks for both Direct and Associated Matching. They verify the selected fields appear in the configured condition, incompatible Direct references can be corrected in Associated mode, the unsaved condition draft survives tab navigation, and Test Rule sees the amended condition. The gallery has no operational Save endpoint: persistence remains the consuming application's responsibility.
